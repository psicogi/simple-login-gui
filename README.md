# Simple Login GUI 

Um sistema de login funcional desenvolvido em Java para praticar conceitos de interface gráfica e integração com Maven.

##  Funcionalidades
* Interface responsiva utilizando `GridPane`.
* Validação simples de credenciais no Controller.
* Estilização personalizada via CSS inline no FXML.

##  Tecnologias
* **Java 21**
* **JavaFX 21**
* **Maven** (Gerenciamento de dependências)

##  Como executar
1. Clone o repositório.
2. Certifique-se de ter o JDK 21 instalado.
3. Execute o projeto através da classe `Launcher.java`.

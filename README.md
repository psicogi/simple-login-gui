# Simple Login GUI 

Um sistema de login funcional desenvolvido em Java para praticar conceitos de interface gráfica e integração com Maven.

##  Funcionalidades
* Interface responsiva utilizando `GridPane`.
* Validação simples de credenciais no Controller.
* Estilização personalizada via CSS inline no FXML.

##  Tecnologias
* **Java 21**
* **JavaFX 21**
* **Maven** (Gerenciamento de dependências)

##  Como executar
1. Clone o repositório.
2. Certifique-se de ter o JDK 21 instalado.
3. Execute o projeto através da classe `Launcher.java`.

##

A functional login application built with Java to practice GUI concepts, styling, and Maven project management.

##  Features
* **Responsive Layout:** Developed using `GridPane` for clean alignment of labels and fields.
* **Input Validation:** Backend logic to verify user credentials with console feedback.
* **Custom Styling:** Enhanced visual identity using inline CSS within the FXML.

##  Tech Stack
* **Java 21:** Utilizing modern language features and modularization.
* **JavaFX 21:** For building the graphical user interface.
* **Maven:** For dependency management and build automation.
